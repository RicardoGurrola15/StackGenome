# Skill: Ecosystem Adapters

## Objetivo

Añadir soporte sin modificar el núcleo.

## Checklist

- manifest/lockfile;
- parsing seguro;
- no ejecución;
- PURL;
- direct/transitive;
- scopes;
- workspaces;
- frameworks;
- evidence;
- confidence;
- warnings;
- fixtures;
- nivel de soporte.

## Prohibido

- afirmar compatibilidad sin regla;
- interpretar código arbitrario;
- descargar dependencias;
- ejecutar package managers.
