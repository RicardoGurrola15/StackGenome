# Skill: StackGenome Architecture

## Usar cuando

- se cambian límites;
- se añade componente;
- se adopta dependencia central;
- se modifica ProjectGraph/API;
- se propone plugin o backend.

## Reglas

- dominio independiente de UI/infra;
- interfaces solo en límites;
- adaptadores compilados en MVP;
- evidence-first;
- deterministic;
- no LLM;
- no ruta local en producto;
- ADR para cambios grandes.

## Salida

- contexto;
- opciones;
- decisión;
- consecuencias;
- pruebas;
- migración;
- ADR.
