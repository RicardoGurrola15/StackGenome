# ADR-0005: Cloudflare para backend futuro

- Estado: aceptado preliminar
- Fecha: 2026-07-24

## Decisión

Diseñar el backend futuro para Workers + D1; R2 posterior.

## Condición

Revalidar límites, costos, portabilidad y necesidades al llegar a la fase 12.

## Consecuencia

El dominio y ranking no deben depender de APIs propietarias; deben ser probables localmente.
