# ADR-0004: Sin IA dentro del MVP

- Estado: aceptado
- Fecha: 2026-07-24

## Decisión

No usar LLM para detección, ranking ni explicación.

## Razones

- consistencia;
- costo;
- privacidad;
- trazabilidad;
- evita recursos inventados.

## Reconsideración

Solo ante una necesidad medida, por ejemplo búsqueda natural opcional, sin sustituir filtros ni ranking.
