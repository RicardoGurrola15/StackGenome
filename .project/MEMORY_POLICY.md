# Política de memoria

## Canonical

Documentos Git y ADR.

## Engram

Auxiliar, project-scoped con nombre StackGenome.

## Retener

- decisiones;
- errores/soluciones;
- fases;
- riesgos;
- comandos de verificación;
- próximos pasos.

## Excluir

- secretos;
- datos personales;
- código extenso;
- contenidos de otros proyectos;
- información ajena a StackGenome.

## Revisión

Antes de `engram sync`, revisar el contenido exportado.
